# NEON APEX — 3D Racing Game

도시 야간 서킷에서 세 명의 AI 레이서와 3랩을 겨루는 브라우저 3D 레이싱 게임입니다.

## 주요 기능

- Three.js로 구현한 네온 스타일 3D 도시 서킷
- 서로 다른 속도와 주행 라인을 사용하는 AI 경쟁자 3명
- 현재 순위, 랩, 경기 시간, 속도 및 기어를 보여주는 HUD
- 사용하면 감소하고 자동으로 재충전되는 니트로 부스트
- 플레이어를 부드럽게 따라가는 후방 카메라와 부스트 시야각 효과
- 체크무늬 출발선, 가드레일, 도시 건물, 별과 네온 조명
- 완주 순위 표시 및 재경기 기능

## 게임 시작하기

1. 터미널에서 게임 폴더로 이동합니다.

   ```bash
   cd racing-game
   ```

2. 로컬 웹 서버를 실행합니다. Python 3가 설치되어 있다면 다음 명령을 사용하세요.

   ```bash
   python3 -m http.server 8000
   ```

3. 브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다.

4. **RACE NOW** 버튼을 누르고 카운트다운이 끝나면 출발하세요.

> 처음 열 때는 Three.js와 글꼴을 불러오기 위해 인터넷 연결이 필요합니다.

`index.html` 파일을 직접 더블 클릭하면 브라우저의 모듈 보안 정책 때문에 게임이 실행되지 않을 수 있습니다. 반드시 위와 같이 로컬 웹 서버를 이용하세요.

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` 또는 `↑` | 가속 |
| `S` 또는 `↓` | 브레이크 / 후진 |
| `A` 또는 `←` | 왼쪽 조향 |
| `D` 또는 `→` | 오른쪽 조향 |
| `Shift` + 가속 | 니트로 부스트 |

니트로 게이지는 가속하지 않을 때 천천히 다시 충전됩니다. 화면 왼쪽의 청록색 막대로 잔량을 확인할 수 있습니다.

## 목표와 팁

- 총 3랩을 가장 먼저 완주하면 승리합니다.
- 트랙 가장자리에 너무 가까이 붙지 말고, 코너에서 차선을 부드럽게 바꾸세요.
- 긴 직선에서 니트로를 사용하면 경쟁자를 추월하기 쉽습니다.
- 경기 종료 화면에서 **RACE AGAIN**을 누르면 새 레이스가 시작됩니다.

| 위치 | 표시 내용 |

## 문제 해결

### 화면이 비어 있거나 3D 그래픽이 나오지 않는 경우

- 인터넷 연결 상태를 확인하세요. Three.js는 CDN에서 불러옵니다.
- 브라우저의 WebGL 하드웨어 가속이 활성화되어 있는지 확인하세요.
- 파일을 직접 열지 말고 `python3 -m http.server 8000`으로 실행하세요.

### 키보드가 동작하지 않는 경우

- 게임 화면을 한 번 클릭한 뒤 다시 조작해 보세요.
- 한글 입력 상태라면 영문 입력 상태로 변경하세요.

### 포트 8000이 이미 사용 중인 경우

다른 포트로 서버를 실행할 수 있습니다.

```bash
python3 -m http.server 8080
```

이 경우 브라우저에서 `http://localhost:8080`을 여세요.

## 최근 그래픽 및 주행 개선

- 차량의 전방 축을 트랙 접선과 일치시켜 주행 중 회전해 보이던 현상을 수정했습니다.
- 조향 각도와 후방 카메라 이동을 보간해 화면 흔들림을 줄였습니다.
- 색상 출력, 톤 매핑, 소프트 섀도를 적용해 야간 장면의 가독성을 개선했습니다.
- 출발선, 가드레일, 차량 조명, 언더글로우와 별 배경을 추가했습니다.
- 출발 지점에서 후진할 때 랩과 순위가 잘못 계산되는 상황을 방지했습니다.
